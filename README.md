# GLAVAT FIGHTERS

Браузерный 2D arcade fighter на Node.js, Canvas, SVG sprite atlas и WebSocket.

## Запуск

Требуется Node.js 18+.

```bash
npm install
npm start
```

Откройте `http://localhost:3000`.

## Управление

- Игрок 1: ← / → движение, ↑ прыжок, ↓ присесть, Shift бег, A удар, S удар ногой, D блок, F супер, Q уклон, E захват.
- Удержание A или S заряжает тяжёлый удар.
- Игрок 2 (локальный режим): H / ; движение, I прыжок, N присесть, M бег, J / K удары, L блок, U супер, O захват, Y уклон.
- На телефоне используйте сенсорные кнопки под ареной. Удерживайте кнопки движения/блока; кнопки действий поддерживают pointer events.
- Для онлайн-матча оба игрока вводят один код комнаты. Владелец комнаты может поделиться ссылкой-приглашением.

## Реализовано

- Главное меню, выбор бойца и пять арен: крыша на закате, ночной город, додзё, подпольный клуб, неоновая улица.
- Два оригинальных бойца в SVG sprite atlas. Для каждого подготовлено 17 отдельных поз: idle, шаги, run, jump, crouch, punch, heavy punch, kick, block, hit, knockback, special, grab, dodge, guard и финальные состояния.
- CPU-режим, локальный режим 1 на 1 на одной клавиатуре, онлайн-комнаты на двух игроков, серия до двух побед.
- Удары, тяжёлые удары, воздушные атаки, захват/бросок, блок с chip damage, уклонение с коротким окном неуязвимости, прыжок, суперприём, оглушение и отбрасывание.
- Эффекты попаданий, частицы, hit-stop, тряска камеры, синтезированная аркадная музыка и звуковые эффекты.
- Аркадные голосовые объявления через встроенный speech synthesis браузера; громкость музыки и эффектов регулируется отдельно.
- Мобильная раскладка кнопок, запрет прокрутки страницы во время игры, масштабирование Canvas под экран.
- Онлайн-сервер принимает игровые input-команды, симулирует скорость, прыжок, гравитацию и столкновения, проверяет атаки, блок, урон, энергию и таймер раунда. Клиент делает локальное предсказание, а серверные snapshots корректируют отображение.
- Автоматические интеграционные тесты для WebSocket-комнат, перемещения, ударов, блока, захвата, ограничения игроков, независимых комнат и повторного подключения.

## Статистика и база данных

Сервер содержит API `/api/profile` и `/api/leaderboard`, а также запись итогов онлайн-матча в PostgreSQL, если задана переменная `DATABASE_URL`. Для включения постоянной статистики необходимо подключить PostgreSQL к сервису и задать эту переменную. На текущем Railway workspace создание дополнительного ресурса отклонено ограничением тарифа, поэтому база данных не подключена и постоянная статистика/лидерборд в production пока недоступны.

## Ограничения, которые важно знать

- 17 поз — это подготовленные sprite-позы, а не 17 полноценных покадровых анимационных клипов с несколькими вручную нарисованными кадрами каждый.
- Онлайн-движение и столкновения рассчитываются сервером; клиентское предсказание сглаживает ввод. Полноценный rollback netcode, историческая реконструкция кадров и компенсация задержки ещё не реализованы.
- Голосовые объявления используют системный синтез речи браузера; это не записанный профессиональный голос аркадного диктора. Поддержка голоса зависит от браузера и его языковых голосов.
- Серверные интеграционные тесты автоматизированы, но два физических телефона iPhone/Android одновременно в этой среде недоступны, поэтому сквозной тест двух реальных устройств не заявляется.
- PostgreSQL не подключён из-за лимита ресурсов Railway; API статистики отвечает статусом 503 до подключения базы.

## Проверки

Production build запускает `npm install && npm test` перед публикацией. Тесты проверяют доставку sprite atlas, создание и соединение комнат, серверное движение и боевые события.
