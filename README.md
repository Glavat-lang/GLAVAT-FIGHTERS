# GLAVAT FIGHTERS — prototype 0.1

## Что уже есть
- Адаптивная аркадная сцена для телефона.
- Два пиксельных бойца, здоровье и HUD.
- Сенсорные кнопки движения, прыжка, удара, ноги, блока и суперудара.
- Тренировочный режим с простым CPU.
- WebSocket-комнаты на двоих: введите одинаковый код комнаты на двух устройствах.

## Локальный запуск
Требуется Node.js 18+.

```bash
npm install
npm start
```

Откройте http://localhost:3000. Для двух телефонов в одной Wi-Fi сети используйте локальный IP компьютера и порт 3000.

## Деплой на Railway
Подключите этот GitHub-репозиторий к Railway. Команда запуска: `npm start`. Railway автоматически задаёт `PORT`.

## Важно
Это ранний технический прототип, не финальная игра. Следующий этап — серверная авторитетная физика, корректное определение попаданий, спрайтовые анимации, reconnect и защита от рассинхронизации.
