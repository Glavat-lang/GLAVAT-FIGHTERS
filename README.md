# GLAVAT FIGHTERS

Браузерный 2D arcade fighter на Node.js, Canvas, SVG sprite atlas и WebSocket.

## Запуск

Требуется Node.js 18+.

```bash
npm install
npm start
```

Откройте `http://localhost:3000`.

## Управление

- Игрок 1: ← / → движение, ↑ прыжок, ↓ присесть, Shift бег, A удар, S удар ногой, D блок, F супер, Q уклон, E захват.
- Удержание A или S заряжает тяжёлый удар.
- Игрок 2 (локальный режим): H / ; движение, I прыжок, N присесть, M бег, J / K удары, L блок, U супер, O захват, Y уклон, P контратака.
- На телефоне используйте сенсорные кнопки под ареной. Удерживайте кнопки движения/блока; кнопки действий поддерживают pointer events.
- Для онлайн-матча оба игрока вводят один код комнаты. Владелец комнаты может поделиться ссылкой-приглашением.

## Реализовано

- Главное меню, выбор бойца и пять арен: крыша на закате, ночной город, додзё, подпольный клуб, неоновая улица.
- Два оригинальных бойца в SVG sprite atlas. Для каждого бойца подготовлен атлас из 17 ключевых пиксельных кадров. В игре работают временные клипы для idle, ходьбы вперёд/назад, бега, прыжка, приседа, обычного и усиленного удара руками/ногами, блока, hit reaction, knockback, special/super, KO, victory, grab, dodge и counter. Кадры переключаются по фазам атаки, таймеру состояния и направлению движения; в онлайне направление шага берётся из серверной скорости.
- CPU-режим, локальный режим 1 на 1 на одной клавиатуре, онлайн-комнаты на двух игроков, серия до двух побед.
- Удары, тяжёлые удары, воздушные атаки, захват/бросок, блок с chip damage, уклонение с коротким окном неуязвимости, прыжок, суперприём, оглушение и отбрасывание.
- Эффекты попаданий, частицы, hit-stop, тряска камеры, синтезированная аркадная музыка и звуковые эффекты.
- Аркадные голосовые объявления через встроенный speech synthesis браузера; громкость музыки и эффектов регулируется отдельно.
- Мобильная раскладка кнопок, запрет прокрутки страницы во время игры, масштабирование Canvas под экран.
- Онлайн-сервер принимает игровые input-команды, симулирует скорость, прыжок, гравитацию и столкновения, проверяет атаки, блок, урон, энергию и таймер раунда. Клиент делает локальное предсказание, а серверные snapshots корректируют отображение.
- Автоматические интеграционные тесты для WebSocket-комнат, перемещения, ударов, блока, захвата, ограничения игроков, независимых комнат и повторного подключения.

## Статистика и база данных

Production использует постоянное хранилище статистики на отдельном Railway Volume, смонтированном в `/data`. Путь к файлу задаётся через `STATS_FILE=/data/fighter-stats.json`. Идентификатор игрока хранится в защищённой cookie `gf_player`; после завершения онлайн-чемпионата сохраняются матчи, победы, поражения, ничьи, нокауты, серии побед и частота выбора каждого бойца. API: `/api/profile` и `/api/leaderboard`; production healthcheck `/health` также подтверждает доступность хранилища. Запись выполняется атомарной заменой файла, чтобы не оставлять частично записанную статистику при перезапуске процесса.

## Ограничения, которые важно знать

- 17 поз — это ключевые спрайтовые кадры. Удары используют последовательности этих поз и фазы восстановления, но это ещё не полноценные вручную нарисованные покадровые клипы уровня коммерческого файтинга.
- Онлайн-движение, прыжки, гравитация, столкновения и попадания рассчитываются сервером; клиент предсказывает своё движение и плавно интерполирует удалённого бойца по snapshots. Полноценный rollback netcode, историческая реконструкция кадров и компенсация задержки ещё не реализованы.
- Голосовые объявления используют системный синтез речи браузера; это не записанный профессиональный голос аркадного диктора. Поддержка голоса зависит от браузера и его языковых голосов.
- Автоматические интеграционные тесты прошли: HTTP healthcheck и доступность хранилища, комнаты и два слота, перемещение, стартовые координаты, прыжок, воздушный удар, уклонение, обычный и тяжёлый удары, блок, контратака, захват, KO, серия до двух побед, сохранение статистики после перезапуска процесса, отказ третьему игроку, независимые комнаты и восстановление матча тем же игроком. Два физических телефона iPhone/Android одновременно в этой среде недоступны, поэтому сквозной тест двух реальных устройств не заявляется.

## Проверки

Production build запускает `npm run validate && npm test` перед публикацией. Healthcheck `/health` подтверждает, что постоянное файловое хранилище доступно для чтения и записи. Тесты проверяют доставку sprite atlas, создание и соединение комнат, серверное движение, стартовые координаты раунда, прыжок, воздушный удар, уклонение от удара, обычный и тяжёлый урон, блок, контратаку, захват, ограничение игроков, независимые комнаты и повторное подключение.
