# GLAVAT FIGHTERS

Браузерный 2D arcade fighter на Node.js и Canvas с собственным SVG sprite atlas и WebSocket-комнатами.

## Запуск
Требуется Node.js 18+.

```bash
npm install
npm start
```

Откройте `http://localhost:3000`.

## Управление
- Клавиатура: ← / → — движение, ↑ — прыжок, A — удар, S — удар ногой, D — блок, F — суперприём.
- Удерживайте A или S, чтобы зарядить тяжёлый удар.
- На телефонах используйте сенсорные кнопки под ареной.
- Для онлайн-матча оба игрока вводят один код комнаты. После подключения доступна ссылка-приглашение.

## Текущая сборка
- Два оригинальных бойца в отдельном sprite atlas: уличный боец и боец в ги.
- 12 поз/кадров на каждого: стойка, шаг, удар, тяжёлый удар, удар ногой, прыжок, блок, получение удара, нокаут и победа.
- Пять визуальных арен: закатная крыша, ночной город, додзё, подпольный клуб и неоновая улица.
- Локальный режим против CPU, три раунда, здоровье, энергия суперприёма, комбо, тяжёлые атаки, частицы, тряска камеры, hit-stop и процедурная chiptune-музыка.
- Сенсорное управление и адаптивная сцена для мобильных экранов.

## Онлайн-архитектура
- Приватные WebSocket-комнаты на двух игроков и ссылки-приглашения.
- Сервер проверяет направление, дистанцию, блок, задержку и активный момент атаки.
- Сервер рассчитывает урон, здоровье, энергию, оглушение, таймер и завершение раунда.
- Состояния и результаты попаданий рассылаются обоим клиентам; отключение игрока обрабатывается сервером.

## Что ещё не реализовано
Это заметно расширенная играбельная сборка, но не законченный коммерческий файтинг. Пока отсутствуют полный набор из 17 отдельных анимаций на бойца, захваты и уклонения, выбор персонажа, полноценная серверная физика движения/rollback netcode, голосовые реплики, сохранение статистики и результатов. Позиции игроков в онлайне передаются клиентами, а сервер авторитетно проверяет атаки и результаты попаданий.
