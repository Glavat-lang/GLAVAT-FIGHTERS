# GLAVAT FIGHTERS

Браузерный 2D arcade fighter. Проект запускается как Node.js-приложение и использует WebSocket для приватных онлайн-комнат.

## Запуск
Требуется Node.js 18+.

```bash
npm install
npm start
```

Откройте `http://localhost:3000`.

## Управление
- Клавиатура: ← / → — движение, ↑ — прыжок, A — удар, S — удар ногой, D — блок, F — суперприём.
- Сенсорное управление: кнопки под ареной.
- В онлайн-режиме два игрока вводят один и тот же код комнаты. После подключения можно скопировать ссылку-приглашение.

## Онлайн-архитектура
- WebSocket-комнаты на два подключения.
- Сервер проверяет направление, дистанцию, блок, задержку атаки и доступность суперприёма.
- Сервер рассчитывает урон, здоровье, оглушение, энергию, таймер и завершение раунда.
- Атака имеет серверную задержку до проверки попадания; положение цели перепроверяется в момент активного кадра.
- Сервер отправляет состояние боя обоим клиентам и отслеживает отключение игрока.

## Ограничения текущей сборки
Это развиваемая ранняя версия, а не законченный коммерческий файтинг. В ней ещё нет полноценного покадрового sprite-sheet пайплайна, набора из пяти законченных арен, записи результатов и полноценного сетевого rollback/netcode. Не следует считать эти функции реализованными.
